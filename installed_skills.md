# 🛠️ Installed Antigravity AI Skills

This document serves as a cheat sheet for all the AI Agent skills currently installed in your project workspace (`.agent/skills/`). The AI agent will automatically reference and enforce these guidelines, methodologies, and processes when working in this repository.

## 🏗️ Workflow & Development Standards
* **`brainstorming`**: Used before creative or constructive work to transform vague ideas into validated designs through disciplined reasoning and collaboration.
* **`concise-planning`**: Always structures, plans, and breaks down tasks into clear steps *before* taking action or writing code.
* **`lint-and-validate`**: Automatically applies quality control, formatting checks, and static analysis after code modifications.
* **`git-pushing`**: Safely stages, commits (using conventional commit messages), and pushes work to the remote repository when requested or automatically during workflows.
* **`git-sync-on-change`**: Automatically syncs code (pull and push) to your Git remote after generating or completing new features and functions.

## 🐛 Debugging & Quality
* **`systematic-debugging`**: Enforces a strict, professional debugging framework: it mandates finding the true root cause, gathering evidence, and making single hypothesis tests *before* writing any patches.
* **`kaizen`**: Operates with a continuous improvement mindset, suggesting refactors, error proofing, and improved standardization.
* **`production-code-audit`**: Autonomously deep-scans the entire codebase line-by-line right before shipment to transform logic into professional, corporate-grade code with maximum optimizations and security.
* **`prompt-engineering`**: Leverages advanced expert patterns and best practices for creating and optimizing AI prompts. Useful for fine-tuning LLM outputs within the codebase (e.g., generating prompts for LLM integrations like your newly added AI Content Studio).

## 🎨 Frontend & UI/UX

## 🤖 AI Engineering & Agent Building

* **`ai-agents-architect`**: Designs and builds autonomous AI agents with tool use, memory systems, planning strategies (ReAct loop, Plan-and-Execute), and multi-agent orchestration. Activate when: *"build an agent", "autonomous agent", "tool calling", "multi-agent system"*.
* **`langgraph`**: Expert in LangGraph — the production-grade framework for stateful, multi-actor AI applications. Covers StateGraph construction, state reducers, conditional routing, checkpointers, human-in-the-loop, and streaming execution. Activate when: *"build with langgraph", "stateful agent", "graph workflow"*.
* **`rag-engineer`**: Designs Retrieval-Augmented Generation (RAG) systems. Masters embedding pipelines, vector databases, semantic chunking (by meaning, not token count), hierarchical retrieval, and hybrid search (BM25 + vector). Activate when: *"build a RAG", "semantic search", "vector search", "chatbot over docs"*.
* **`mcp-builder`**: Complete guide for creating high-quality MCP (Model Context Protocol) servers in TypeScript or Python. Covers tool design, input/output schemas (Zod/Pydantic), error handling, transport selection (stdio vs HTTP), and evaluation. Activate when: *"build an MCP server", "create MCP tools", "integrate external API via MCP"*.
* **`agent-evaluation`**: Framework for testing and benchmarking LLM agents using behavioral contract testing, statistical evaluation (multi-run), adversarial testing, and reliability metrics. Prevents benchmark-to-production gaps. Activate when: *"evaluate my agent", "agent benchmarks", "test LLM reliability"*.
* **`prompt-engineering`**: Expert guide on advanced prompt engineering patterns — chain-of-thought, few-shot learning, structured output, and LLM behavior optimization. Activate when: *"improve my prompt", "LLM output quality", "prompt strategy"*.
